One line a smart fridge texts its owner at 3am, written by `main.ts` to `/output/entry.txt`.

> 3:04 AM. Third visit tonight. Pickles left: two. I'm not judging you, I'm a fridge. Go to bed before I start charging rent.

Run with Node 22+: `node main.ts`. The program self-checks the gate (1–140 characters, single line) before writing.
